## تبدیل دودویی به دهدهی چه می‌گوید؟

ارزش هر رشتهٔ دودویی، جمع وزن جایگاه‌هایی است که بیتشان ۱ است:

<Formula
  id="binary-to-decimal"
  latex={"(b_{n-1} \\cdots b_1 b_0)_2 = \\sum_{i=0}^{n-1} b_i \\times 2^i"}
  caption="جمع وزن‌ها: ارزش دهدهی یک رشتهٔ دودویی"
/>

<FormulaBreakdown
  title="اجزای فرمول"
  terms={[
    { term: "b_i", label: "بیت جایگاه iام", detail: "فقط صفر یا یک؛ از راست با صفر شروع می‌شود" },
    { term: "2^i", label: "وزن جایگاه", detail: "۱، ۲، ۴، ۸ و همین‌طور جلو" },
    { term: "\\sum", label: "جمع", detail: "فقط جایگاه‌هایی که بیتشان ۱ است در جمع اثر دارند" },
  ]}
/>

<Callout type="tip" title="کاربرد">
  همین فرمول را برای تبدیل مبنای ۸ (با ۸ به توان i) و مبنای ۱۶ هم می‌شود به کار برد؛ فقط مبنا عوض می‌شود. یک <a href="/examples/dec-bin-convert">مثال حل‌شدهٔ تبدیل</a> را قدم‌به‌قدم ببین.
</Callout>
