## مبناهای ۸ و ۱۶: بسته‌بندی بیت‌ها

نوشتن رشته‌های طولانی صفر و یک خسته‌کننده و پرخطاست، پس بیت‌ها را **بسته‌بندی** می‌کنیم:

- هر **۳ بیت** یک رقم مبنای ۸ (octal) می‌شود، چون <Formula inline latex={"2^3 = 8"} />.
- هر **۴ بیت** یک رقم مبنای ۱۶ (hex) می‌شود، چون <Formula inline latex={"2^4 = 16"} />.

<Formula
  id="grouping-example-oct"
  latex={"101101_2 = \\underbrace{101}_{5}\\,\\underbrace{101}_{5} = 55_8"}
  caption="بسته‌بندی سه‌تایی برای مبنای ۸"
/>

<Formula
  id="grouping-example-hex"
  latex={"101101_2 = \\underbrace{0010}_{2}\\,\\underbrace{1101}_{D} = 2D_{16}"}
  caption="بسته‌بندی چهارتایی برای مبنای ۱۶"
/>

رقم‌های هگز از ۰ تا ۹ و بعد A تا F هستند (A=۱۰ تا F=۱۵). برای تبدیل برعکس، هر رقم را به ۳ یا ۴ بیت باز کن.

<Callout type="warning" title="جهت بسته‌بندی">
  بسته‌بندی همیشه **از ممیز به بیرون** شروع می‌شود: برای قسمت صحیح از راست، برای قسمت کسری از چپ. اگر از سمت اشتباه شروع کنی، گروه‌ها جابه‌جا می‌شوند.
</Callout>

## کسرهای دودویی

وزن جایگاه‌ها بعد از ممیز با توان‌های منفی ادامه پیدا می‌کند: <Formula inline latex={"2^{-1} = 0.5"} />، <Formula inline latex={"2^{-2} = 0.25"} />، <Formula inline latex={"2^{-3} = 0.125"} /> و همین‌طور جلو.

<Formula
  id="binary-fraction-example"
  latex={"101.101_2 = 4 + 0 + 1 + 0.5 + 0 + 0.125 = 5.625"}
  caption="ارزش یک عدد کسری دودویی"
/>

برای تبدیل قسمت کسری دهدهی به دودویی، برعکس قسمت صحیح عمل کن: آن‌قدر در ۲ **ضرب** کن و قسمت‌های صحیح را از **اول به آخر** بخوان. مثلاً <Formula inline latex={"0.625 \\times 2 = 1.25 \\to 0.25 \\times 2 = 0.5 \\to 0.5 \\times 2 = 1.0"} /> پس <Formula inline latex={"0.625 = 0.101_2"} />.

<Confused prerequisites={["binary-to-decimal"]} retry="عدد 2D هگز را به دودویی باز کن و بعد همان را سه‌تاسه‌تا بسته‌بندی کن">
  اگر هگز و مبنای هشت قاطی شده‌اند، فقط اندازهٔ بسته را عوض کن: هگز همیشه چهارتایی، مبنای هشت همیشه سه‌تایی. جهت شروع (از ممیز) در هر دو یکی است.
</Confused>
